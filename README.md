# Travel Tracker

## Proposal

For my Final Project, I would like to build a website for tracking your travel where users can enter information about their trips and travel. The first thing a user will be able to do is create, edit and delete trips. The features that a user can add into a trip will be destination, dates, budget, travelers and activities. I really like the idea of this project because I spent 5 weeks traveling in Ecuador this summer. This assignment would be a fun way for me to organize travel information and also practice what I have learned in this class. I want to organize my website into multiple pages, where styling is apparent, where I will then implement drag and drop, search and filter, and implement an external api to view details about the destination. I want the application to feel complete and user friendly.
